# Forgetting

**Forgetting**: exponential forgetting in the unit 10 map, decaying toward zero or toward the prior: γ as a memory of 1/(1 − γ) looks, how fast the map drops a bump that vanishes, and what forgetting costs when nothing changes

No tutorial fits this unit, so steps 13–21 of my Bench worksheet are the tutorial. The precedents come from recursive least squares: exponential forgetting, estimator windup, directional forgetting and variable forgetting factors.

Credit: the introduction of Shin and Lee's [*A New Exponential Forgetting Algorithm for Recursive Least-Squares Parameter Estimation*](https://arxiv.org/abs/2004.03910) (2020) surveys those precedents.
